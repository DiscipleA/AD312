# Queries with TanStack Query

This Week 04 lecture explains the `useQuery` hook as the connection point between a React component, a query key, and a query function.

Use this folder for:
- notes on the query object returned by `useQuery`
- loading, error, success, and fetching-state examples
- query key and query function reference patterns
- lightweight source examples parallel to the runtime lecture
