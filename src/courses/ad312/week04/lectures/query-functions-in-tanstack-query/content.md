# Query Functions in TanStack Query

This Week 04 lecture explains query functions as the Promise-based data retrieval layer used by TanStack Query.

Students learn how query functions resolve data, throw errors, integrate with the native Fetch API, extract variables from query keys, and use QueryFunctionContext features such as AbortSignal for cancellation.

The runtime lecture component lives in `src/lectures/Week04QueryFunctionsInTanStackQueryMasterclass.jsx`; this folder is the lightweight course-source mirror that matches the existing Week 01, Week 02, and Week 03 mirror-layer pattern.
