# Introduction to Immer

This Week 03 lecture extends the existing array-and-immutability unit by introducing Immer as a readability helper for nested immutable updates.

## Core teaching goals

- Explain what Immer is and why it exists.
- Show how `produce()` creates a draft-based workflow.
- Compare manual immutable updates with Immer-powered updates.
- Introduce curried producers as a reusable pattern for React state setters.
- Preserve the same masterclass depth and code visibility already used in Weeks 01–03.
