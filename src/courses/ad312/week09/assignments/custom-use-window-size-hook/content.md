# Week 9 Assignment 2 - Packaging Reusable Logic into a Custom Hook

Create a reusable `useWindowSize` custom hook for a streaming website layout. The hook synchronizes browser width and height with React state, uses `useEffect` to listen for resize events, removes the listener during cleanup, and powers a GUI that switches between Mobile and Full layouts.

The runtime guide lives in `src/exercises/Week09UseWindowSizeAssignmentGuide.jsx`.

The completed hook, preview component, tests, and README live in `src/assignments/week09/custom-use-window-size-hook/`.
