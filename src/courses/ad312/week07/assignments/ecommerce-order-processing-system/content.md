# E-Commerce Order Processing System

Build a raw JavaScript singly linked-list order system. Orders are appended in arrival order, then the list is reversed so the newest orders are processed first.

## Requirements

- Define an `Order` class with order ID, customer details, order details, and relevant status information.
- Implement a singly linked list with `append(order)`, `display()`, and `reverse()` behavior.
- Reverse the list by manipulating node links.
- Include three normal console-log tests and three edge console-log tests.
- Explain time and space complexity.
