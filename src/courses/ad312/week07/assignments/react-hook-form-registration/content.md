# Week 7 Assignment 2: Advanced Performance Forms with React Hook Form

Build a Vite React user registration form with React Hook Form. Register Full Name, Email Address, Password, Confirm Password, Role / Account Type, and Terms & Conditions fields with validation declared inside `register` configuration objects.

The implementation should restore cached drafts from `localStorage` with `setValue`, synchronize changes with `watch`, show `isSubmitting` loading state during a simulated async request, reset the form after success, and clear the saved draft.

Testing uses Vitest and React Testing Library with normal and edge cases.
