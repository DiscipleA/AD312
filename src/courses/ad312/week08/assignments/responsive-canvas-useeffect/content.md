# Week 8 Assignment 2 — Mastering useEffect with a Responsive Canvas

Build a Vite React responsive canvas that listens to the browser window size with `useEffect`.

The component displays the current width and height, switches between Mobile and Desktop visual modes, attaches a `resize` event listener, and removes that listener during cleanup to prevent memory leaks.

The guide includes a working preview, Live Test Results, full source code, and Vitest coverage.
