# Implementing and Analyzing Selection Sort

Implement Selection Sort in raw JavaScript, test it with required normal and edge cases, analyze time and space complexity, discuss stability, and generate a downloadable report from the GUI.

## Requirements

- Sort an integer array in ascending order.
- Include comments explaining each major step.
- Test random, sorted, descending, all-same, empty, and single-element arrays.
- Explain why nested loops create O(n²) time complexity.
- Explain why the regular implementation is in-place with O(1) extra space.
- Discuss Selection Sort stability.
- Include optional descending and stable-variant enhancements.
