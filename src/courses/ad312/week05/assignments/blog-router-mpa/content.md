# Blog Multi-Page App with React Router

Week 05 Assignment 03 asks students to convert a static single-view Blog application into a React Router / Remix-style multi-page app.

Students create `app/root.jsx`, `app/routes/_index.jsx`, `app/routes/about.jsx`, `app/routes/post.$postId.jsx`, and `app/data/posts.js`.

The runtime guide uses a Vite-safe bridge to demonstrate Home, About, dynamic Post, route params, and useNavigate-style programmatic navigation.
