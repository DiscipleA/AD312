# Recipe Gallery Routing with React Router

Week 05 Assignment 02 continues the Week 2 Recipe Gallery by converting the local-state gallery into a routed React Router framework-style application.

Students create a Home route, a Gallery route, and a dynamic Recipe Detail route using `app/routes/_index.jsx`, `app/routes/gallery.jsx`, and `app/routes/recipe.$id.jsx`.

The runtime guide uses a Vite-safe bridge that reuses the Week 2 recipe image data while demonstrating clickable route-link behavior and dynamic recipe ids.
