# Patient Health Record Symmetry

Week 05 Assignment 01 asks students to solve a healthcare-themed linked-list problem in raw JavaScript.

Students define a singly linked-list node, implement `isHealthRecordSymmetric(head)`, and validate the solution with three normal console-log tests and three edge console-log tests.

The runtime assignment guide includes a browser-safe preview, a Live Test Results panel, full source code, and the requested console-log test file.
