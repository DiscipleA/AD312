# React Router Route Patterns

Week 05 Lecture 03 extends React Router by focusing on route configuration and URL pattern matching in the Remix / React Router framework-style model.

Students practice configuring central routes, understanding file naming conventions, reading route modules, composing nested routes, applying route prefixes, working with dynamic and optional segments, and using splats for deep paths and catch-all 404 behavior.

The runtime lecture uses editable DemoComponent-based examples, so each Code in Action preview is powered by the same demo component source shown in the editable code window.
