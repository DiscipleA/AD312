# Navigation with React Router

Week 05 Lecture 04 extends React Router / Remix routing by focusing on navigation behavior.

Students compare declarative navigation with `Link` and `NavLink`, data-driven navigation with `Form`, loader/action redirection with `redirect`, and imperative navigation with `useNavigate`.

The runtime lecture keeps the uploaded DemoComponent behavior as the editable Code in Action source. The shorter original code examples remain visible as colorized static navigation references.
