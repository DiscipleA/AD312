# Introduction to React Router

Week 05 Lecture 02 introduces React Router v7 as a flexible routing system that can scale from declarative client-side routing to data routers and full framework-style route modules.

Students compare Declarative, Data, and Framework modes, learn why route-level loaders and actions matter, and practice thinking about URLs as the structure that connects navigation, data, and UI.

The runtime lecture uses editable DemoComponent-based examples so the code window powers the Code in Action preview without replacing the original demo behavior.
