# Introduction to Singly Linked Lists

Week 05 Lecture 01 introduces singly linked lists as a dynamic linear data structure made from connected nodes.

Students learn how a node stores data plus a `next` reference, why the head node is the entry point, how traversal works, and how insertion and deletion are handled by carefully rewiring references.

The runtime lecture uses editable versions of the uploaded Code in Action demo components, so the visible editable code and the preview include the same richer node-chain behavior.
