# Building a Global Theme/Dark Mode Switcher

Use the React Context API to build a global Light Mode / Dark Mode switcher in a Vite React app.

## Goals

- Create a ThemeContext.
- Build a ThemeProvider with light/dark state.
- Provide a toggleTheme function.
- Wrap the app with the provider.
- Consume context in a ThemeSwitcher component.
- Apply dynamic classes or styles based on the active theme.
- Include Vitest coverage for normal and edge cases.
